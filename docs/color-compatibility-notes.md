# Color and Compatibility Notes for Hot Glass

Color is the part of glass that looks like emotion and behaves like chemistry.

That is a dangerous combination.

## The short version

COE is not compatibility.

It is a number, not a permission slip.

Labels matter. Batch matters. Glass system matters. Heat history matters. Thickness matters. Testing matters. The scrap bucket is not a theological argument. It is a box of unknowns.

## COE is not enough

COE means coefficient of expansion. It describes how much glass expands and contracts over a temperature range. Useful? Yes. Sufficient? No.

Bullseye's compatibility note says the important part plainly: matching COE is not an accurate measure of compatibility by itself. Viscosity matters too. Two glasses can carry similar expansion numbers and still not fit after they are worked, annealed, cooled, and asked to live together forever.

Forever is a long time for a bad assumption.

## Practical shop rules

### Label everything

You will not remember.

That is not a moral failure. It is just how studios work. There are rods, bars, frits, powders, scraps, cane, sheet, notes on tape, notes on bags, notes that fell off bags, and a person who swears they know what it is because they put it there in 2018.

Label it anyway.

```text
Color name:
Manufacturer:
Glass system / COE if published:
Batch or lot:
Form: rod / bar / frit / powder / cane / sheet / scrap
Source:
Date received:
Known tests:
Known failures:
Notes:
```

### Keep systems separate

Common shorthand includes 90, 96, 104, 33, and whatever the hot shop house glass happens to be.

Those are not interchangeable just because the colors are pretty.

| Shorthand | Common Context | Working Assumption |
|---|---|---|
| 90 | Bullseye-style kiln glass | Stay inside the tested system unless you are deliberately testing. |
| 96 | System 96 / Oceanside-style kiln glass | Keep separate from 90 unless you are testing on purpose. |
| 104 | Many soft-glass flameworking rods | Common in beadmaking and lampworking. Not automatically hot-shop compatible. |
| 33 | Borosilicate | Different working range and behavior. Do not treat it like soda-lime glass. |
| House furnace glass | Hot shop | Ask the studio what fits it. Then believe the answer. |

### Treat unknown scrap as unknown

Unknown glass is not free color. It is a test material.

That does not mean never use it. It means do not pretend it is documented when it is not.

## Before using a new color

Ask:

- Is this color approved for this base glass?
- Is it rod, bar, frit, powder, cane, sheet, or mystery?
- Does it need preheating?
- Does it strike, reduce, burn out, liver, boil, or do some other small act of theater?
- Has anyone seen it crack later?
- Has anyone checked it through a polarizer?
- Is my use similar to the test use in thickness, heatwork, and process?

If the answer is "I think so," you do not have an answer yet. You have a place to start a test.

## Warning signs

- Cracks along the color boundary.
- Delayed cracks after pickup.
- Ring cracks around inclusions.
- Coldworking cracks that begin at color joins.
- Stress visible through polarized light.
- A test that works thin but fails thick.
- A color that behaves until you change the heatwork.

## Decision tree

```text
Do I know what this glass is?
|-- No: label unknown, test only, do not use in work that needs to survive.
|-- Yes:
    Is it known to fit this base glass and process?
    |-- No: test it.
    |-- Yes:
        Is my use similar to the known use?
        |-- No: test closer to the real use.
        |-- Yes: proceed, document, and check after cooling.
```
