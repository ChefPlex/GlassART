# GlassART Docs

This folder is the practical side of the repo.

The root README explains why the repo exists. These files are what you hand to somebody who has just made their first piece, or cracked their first piece, or asked whether they can mix this very special mystery color with the shop glass because it was in a box and therefore must be fine.

No. Usually no.

## Files

| File | Use It When |
|---|---|
| [`beginner-resource-guide.md`](beginner-resource-guide.md) | Someone has taken a first class and wants to know what to do next. |
| [`color-compatibility-notes.md`](color-compatibility-notes.md) | You are about to use color, scrap, frit, rod, bar, cane, or something a friend swears is compatible because it was compatible once. |
| [`kiln-schedule-reference.md`](kiln-schedule-reference.md) | You need a clean way to document a kiln schedule, annealer habit, firing result, or failure. Especially failure. |
| [`flamework-to-hot-glass-transition.md`](flamework-to-hot-glass-transition.md) | A torch worker is moving into furnace work and discovering that gravity has opinions. |
| [`public-glass-community-programs.md`](public-glass-community-programs.md) | A class, demo, event, or outreach program needs to be documented so the next version starts smarter. |

## How to use these notes

These are working notes, not commandments. Glass does not reward false authority.

Use them as:

- A starting point for students
- A checklist before a session
- A place to capture studio knowledge
- A structure for program documentation
- A reminder that writing down what failed is not pessimism. It is how the next thing gets better.

Studio policy beats this repo. Manufacturer instructions beat this repo. The person responsible for the equipment beats this repo. The repo is useful, not sovereign.
